# Nerve gives out

> **STANDING — BUILT**  
> Implemented in code and checkable against the tree — a module or a test stands under it.  
> *Derived from the tree — the code is there to be read.*

The most important line in the game, and the only one in the nerve machine with no cushion on it. Everywhere else a unit has to move a good way past a threshold before its state changes, so lines do not flicker. Not here. The instant morale touches the breaking point the unit is running. That asymmetry is deliberate: getting frightened is sudden and getting brave is slow, which is true of people.
