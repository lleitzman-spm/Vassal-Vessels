# Nerve comes back

> **STANDING — BUILT**

> *Derived from the tree — the code is there to be read.*

To go back UP a step a unit must clear the threshold by a margin, not merely touch it. Without that margin a unit sitting exactly on the line would flip between states every tick and the herald would read like a stuck bell. The margin is the same size in both directions between the calm states — it is only the break that has none.
