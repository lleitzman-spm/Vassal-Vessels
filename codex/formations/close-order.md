# Close Order

> **STANDING — BUILT**  
> Implemented in code and checkable against the tree — a module or a test stands under it.  
> *Derived from the tree — the code is there to be read.*

Shoulder to shoulder, each man owning about two-thirds of a square metre. Everything to do with pushing, holding and receiving a charge wants this. Everything to do with not being shot hates it — close order takes three and a half times the arrows loose order does.
