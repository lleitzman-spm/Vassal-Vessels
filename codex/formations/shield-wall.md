# Shield Wall

> **STANDING — BUILT**  
> Implemented in code and checkable against the tree — a module or a test stands under it.  
> *Derived from the tree — the code is there to be read.*

Tighter than close order, shields overlapping so each man is partly covered by his neighbour's. Front shield up by a quarter, shock resistance up, speed down to a crawl — and it is the densest arrow target on the field. The trap: overlap only works while the line HOLDS. Below 300,000 cohesion the shield bonus halves, because the wall has stopped being a wall.
