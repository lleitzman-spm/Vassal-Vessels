# Open Order

> **STANDING — BUILT**  
> Implemented in code and checkable against the tree — a module or a test stands under it.  
> *Derived from the tree — the code is there to be read.*

Spread out with room to move. Arrows mostly go past. So does everything else you might want to do to somebody: you cannot push, cannot hold a line, and can neither deliver nor absorb a charge. Open order is for people who intend not to be there when the fighting happens.
