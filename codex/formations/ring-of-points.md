# Ring of Points

> **STANDING — BUILT**  
> Implemented in code and checkable against the tree — a module or a test stands under it.  
> *Derived from the tree — the code is there to be read.*

A ring of pikemen, points outward all the way round. It solves the pike block's one fatal weakness — that bracing is front-arc only — by having no flanks and no rear at all. Cavalry cannot touch it from any direction. And it cannot move. At all. Ever. So it becomes the densest, most obliging arrow target that has ever existed, standing perfectly still. The correct answer to being surrounded by horsemen, and the worst possible answer to anything else.
