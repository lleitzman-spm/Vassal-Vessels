# Household Guard

> **STANDING — BUILT**  
> Implemented in code and checkable against the tree — a module or a test stands under it.  
> *Derived from the tree — the code is there to be read.*

Your own paid soldiers, who live where you live. No letters, no waiting, no excuses, no grudges — the obedience number on this contingent is the highest in the game, which you will feel every time an order lands. They cost three crowns a man every season whether there is a war or not, and that arithmetic is the whole reason the rest of the feudal system exists.
