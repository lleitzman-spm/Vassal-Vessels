# The Bombard

> **STANDING — BUILT**  
> Implemented in code and checkable against the tree — a module or a test stands under it.  
> *Derived from the tree — the code is there to be read.*

A hooped iron tube on a sledge that throws a stone the size of a man's chest at roughly the right part of the field. It kills almost nobody — but its fear multiplier is near three times a war bow's, and fear is what actually decides battles. It moves at a seventh of walking pace, so wherever you put it at the start is where it is; and one shot in sixteen bursts the tube and kills the crew. A bad investment that everyone wants, which is exactly right.
