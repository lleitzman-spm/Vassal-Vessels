# Court: Act Days

> **STANDING — BUILT**  
> Implemented in code and checkable against the tree — a module or a test stands under it.  
> *Derived from the tree — the code is there to be read.*

What each act of governance costs in DAYS off the deadline, and which track it sits on. This is the whole calendar: there is no end-turn, the clock advances only when an act is placed on a track, and you have the crown's own day-book plus one track for every filled seat. Against a forty-one-day deadline with two seats filled you have 41 crown-days and 82 officer-days, and eleven things worth doing. Coin costs are beside them where they are fixed; where they are a range, the price is read from the act itself.
