# Battle: Refusal

> **STANDING — BUILT**  
> Implemented in code and checkable against the tree — a module or a test stands under it.  
> *Derived from the tree — the code is there to be read.*

A horse will not run onto a set spear point. Refusal is a slowing field projected in front of a braced polearm line or planted stakes, and it is multiplied by how steady and how well-dressed that line is — frightened men with a wobbly line project almost nothing, and get ridden over, which is exactly the rule working. Men on foot feel it too, but only a quarter as strongly and over 30 percent of the distance: a man balks in the last few paces where a horse balks from twelve metres out. FRONT ARC ONLY — a braced block charged in the flank has no refusal at all, which is why pikes need horsemen on their wings.
