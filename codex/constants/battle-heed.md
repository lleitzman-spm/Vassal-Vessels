# Battle: Heed

> *Derived from the tree — the code is there to be read.*

When an improvised order lands, the captain weighs it once — the court's obedience for, danger and dead friends against, a seeded wobble of eight either way — and the score picks one of six outcomes. Every outcome is visible motion and every one is heralded with its cause named. Thresholds are design B's, verbatim; the score is built on the Host's obedience number so a wergild you never paid is a charge that never happens.
