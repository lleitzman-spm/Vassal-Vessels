# Battle: Cohesion

> **STANDING — BUILT**  
> Implemented in code and checkable against the tree — a module or a test stands under it.  
> *Derived from the tree — the code is there to be read.*

How well dressed the ranks are. Standing still fixes it; moving, running, turning, rough ground and being hit wreck it. A ragged unit delivers a weaker charge, braces worse, fights worse — and takes fewer arrows, because it is spread out. Cohesion is the invisible price of every manoeuvre, which is why 'just go round them' is never free. startBase and startPerPoint turn the Host's 0-100 social cohesion into a starting bar (this canon's own bridge — see OPEN-QUESTIONS).
