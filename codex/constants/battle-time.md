# Battle: Time

> **STANDING — BUILT**  
> Implemented in code and checkable against the tree — a module or a test stands under it.  
> *Derived from the tree — the code is there to be read.*

The battle is chopped into twenty slices a second and every slice does exactly the same work in exactly the same order. That is what makes a replay a replay: run it again with the same seed and the same thing happens, down to the last arrow. plannedBattleTicks is the yardstick that turns a latecomer's 'a quarter of the way through' into a tick.
