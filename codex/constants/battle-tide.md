# Battle: Tide

> **STANDING — BUILT**  
> Implemented in code and checkable against the tree — a module or a test stands under it.  
> *Derived from the tree — the code is there to be read.*

The Tide is each side's momentum, READ every second from the last thirty seconds of events with a fifteen-second half-life, clamped to plus or minus 25 — never stored: delete the events and the Tide is gone. Every unit's morale drifts by tide x 8 milli per tick, so winning firms an army up and losing makes it brittle. The fast decay is the anti-snowball: an early advantage evaporates unless pressed.
